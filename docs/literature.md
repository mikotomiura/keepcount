# Literature record

This file records which text of each cited work was read, from which source, and which literature searches were run. It accompanies Appendix H of the article *Can a pause summary show where one writer paused? An audit procedure for keystroke logs*. The searches of 2026-11-01 were made for the earlier preprint (Miura and Harada, 2026) and are kept because the article reuses their results. "Full text" means the whole document was obtained and read; "part" means a document was obtained but only the passages named in the last column were checked against it; "abstract only" means only the abstract in a bibliographic database or publisher page was read.
